## Image Specifications

### Recommended Sizes:
- **Logo**: 500x500px (PNG with transparent background)
- **Hero background**: 1920x1080px minimum
- **Restaurant interior**: 1920x600px
- **Food cards**: 800x600px
- **Specialty items**: 1200x900px
- **Event packages**: 800x800px
- **Chef photos**: 800x600px
- **Footer background**: 1920x600px

### Format Guidelines:
- Use **PNG** for logo (transparent background)
- Use **JPG** for all photos (optimized for web, 70-85% quality)
- Keep file sizes reasonable (< 500KB per image when possible)

## How to Export from Figma

1. Select the image/element in Figma
2. In the right panel, find "Export" section
3. Choose format (PNG for logo, JPG for photos)
4. Set scale to 2x or 3x for high-resolution displays
5. Click "Export [element name]"
6. Save with the corresponding filename in the `images` folder
